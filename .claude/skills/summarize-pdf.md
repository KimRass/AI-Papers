# summarize-pdf

PDF 논문을 읽고 한국어로 요약 정리하는 스킬입니다.

## 사용법

```bash
/summarize-pdf <pdf_파일_경로>
```

## 예시

```bash
/summarize-pdf vision_language/vlm/blip.pdf
/summarize-pdf ./my_paper.pdf
```

## 동작 방식

1. 지정된 PDF 파일에서 텍스트 추출
2. 논문 내용을 읽고 이해
3. 아래 구조에 따라 한국어로 요약 정리
4. 같은 폴더에 `[논문명].md` 파일 생성 (PDF와 동일한 이름)

## 요약 구조

### 1. 📋 논문 정보
제목, 저자, 소속, 발표 학회/년도, arXiv, 코드 링크

### 2. 🎯 핵심 요약
3~5문장. "무엇을 발견했고, 어떻게 했으며, 결과는 무엇인가"를 한 단락으로.

---

### 3. 🧩 핵심 흐름 (직관적 이해) ← 핵심 섹션

논문의 핵심 메커니즘을 **인과적 흐름**으로 3~5단계로 서술한다.

각 단계 작성 규칙:
- **단계 제목**: `N단계 — [행위]: [한 줄 핵심]` 형식
- **도입부**: 이 단계가 왜 필요한가? ("그렇다면 ~은 어떻게?" 형식으로 자연스럽게 연결)
- **설명**: 핵심 개념을 명확하게 서술
- **비유**: 일상적 비유 또는 쉬운 예시를 한 줄 블록인용(`>`)으로 제시
- **실제 예시**: 논문에 등장하는 구체적 수치, 실험 결과, 텍스트 예시를 인용 (`> **실제 예시**:`)
- **연결**: "그래서 다음 단계에서는 ~" 형식으로 다음 단계와 자연스럽게 이어짐

이 섹션은 기술 배경 없이도 읽힐 수 있어야 한다.

---

### 4. 📖 주요 내용
- 연구 배경 및 문제점
- 제안 방법 (수식, 알고리즘 포함)
- 모델/데이터셋 구성

### 5. 📊 실험 결과
- 핵심 성능 비교 표
- 각 수치의 의미와 해석을 표 아래 또는 인라인으로 추가

### 6. 💡 주요 인사이트
이 논문이 기존과 다른 점, 분야에 주는 함의를 불릿으로.

### 7. 🔬 기술적 세부사항
수식, 코드 스니펫, 알고리즘 상세. 깊이 파고드는 독자를 위한 섹션.

### 8. 📌 한계점
방법론적 한계, 일반화 범위, 윤리적 고려사항.

### 9. 🎓 결론
2~3문장. 핵심 발견과 분야에 대한 시사점.

## 작성 원칙

- **구조 순서**: `핵심 흐름` 섹션은 반드시 `주요 내용` 앞에 위치 — 빠른 독자와 깊은 독자를 모두 수용
- **실제 인용 우선**: 비유나 예시는 논문에 실제로 등장하는 입출력 예시, 수치, Figure 캡션을 직접 인용
- **인과 연결**: 단계 간 "그래서(therefore)", "이를 위해(to do this)", "반대로(conversely)" 등의 연결어로 흐름 유지
- **수식은 필요한 곳에**: 핵심 흐름 섹션에는 간단한 수식만, 상세 수식은 기술적 세부사항으로
- 수식, 그림, 표는 텍스트로도 설명
- 이모지 섹션 헤더 유지
