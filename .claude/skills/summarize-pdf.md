# summarize-pdf

PDF 논문을 읽고 한국어로 요약 정리하는 스킬입니다.

## 사용법

```bash
/summarize-pdf <pdf_파일_경로>
```

## 예시

```bash
/summarize-pdf vision_language/vlm/blip.pdf
/summarize-pdf ./my_paper.pdf
```

## 동작 방식

1. 지정된 PDF 파일에서 텍스트 추출
2. 논문 내용을 읽고 이해
3. 한국어로 요약 정리
4. 같은 폴더에 `[논문명].md` 파일 생성 (PDF와 동일한 이름)

## 요약 내용

생성되는 마크다운 파일에는 다음 내용이 포함됩니다:

- 📋 논문 정보 (제목, 저자, 발표년도)
- 🎯 핵심 요약
- 📖 주요 내용
  - 연구 배경 및 문제점
  - 제안 방법/모델 구조
  - 실험 결과
  - 핵심 기여
- 💡 주요 인사이트
- 🔬 기술적 세부사항
- 📊 성능 비교
- 🚀 응용 분야
- 📌 한계 및 향후 과제

## 참고사항

- 수식, 그림, 표는 텍스트로만 설명됩니다
- 원본 PDF도 함께 참조하세요
- 중요한 논문일수록 상세히 작성됩니다
